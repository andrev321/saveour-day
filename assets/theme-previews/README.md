# Historical theme previews

Open [index.html](index.html). Five PNG boards show two layouts for each theme; ten additional `*-split.png` and `*-overlay.png` files show full pages.

These are snapshots of the renderer with sample content and a local photograph, captured on **2026-09-29**. They are historical references, not a guarantee of the current design. For current themes and renderer screenshots, see [Themes and palettes](../../docs/THEMES-AND-PALETTES.md).
