# Staging verification records

Keep dated environment inventories, migration mappings, deployment identifiers, and acceptance evidence in the private operator record. The public guides describe the steps for any installation.

- Use [Staging operations](STAGING-OPERATIONS.md) to configure origins and deploys.
- Use [Testing](TESTING.md) and [Deployment](PLATFORM-DEPLOYMENT.md) for smoke and acceptance checks.
- Compare the database's applied migration history with the files in the repository before changing an existing environment. Some older installations recorded different migration timestamps.
